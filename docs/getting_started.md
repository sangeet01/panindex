# PanIndex (FractalIndex - FRX): Getting Started Guide

This guide covers how to index, query, and visualize pangenomic data using the PanIndex (`frx`) stack.

## 1. Data Ingestion

PanIndex works with standard **GFA 1.0/1.1 (Graphical Fragment Assembly)** files, including those generated by `vg`. 

To begin, you must normalize and annotate your graph with PanIndex tags, and optionally build the k-mer index for sequence searching.

```bash
# Process a standard GFA file or vg-generated GFA
frx vg-import --gfa data/input.gfa --out pangenome.frx.db --build-kmer-index
```

This unified command computes addresses for every node and injects two new tags into the output database:
- `AN:Z:<hex>`: The 32-byte PanIndex ratchet address.
- `PA:Z:<path>`: The human-readable derivation path.

## 2. Querying the Pangenome

The `frx` CLI provides several distinct search modes:

### A. Ratchet Search (Path-based)
Find a node by its categorical path. Best for known chromosomal positions.
```bash
frx query --index pangenome.frx.db --path "PangenomeRoot/Node14"
```

### B. Tag Search (Keyword-based)
Find nodes by Anubandha tags (e.g., AMR gene names, variant IDs).
```bash
frx query --index pangenome.frx.db --tag "AMR:OXA-48"
```

### C. Pattern / Similarity Search (Sequence-based)
Find nodes that contain a specific DNA sequence exactly (`frx pattern`) or heuristically using MinHash/LSH (`frx variant`).
```bash
# Exact k-mer based search
frx pattern --index pangenome.frx.db --pattern ATGCGTA
```

## 3. Handling Real Biological Quirks

PanIndex handles complex biology natively:
- **Plasmids**: Circular DNA is automatically "unrolled" using lexicographic anchoring.
- **HGT**: Horizontal Gene Transfer is tracked via topological "symlinks" between strain subgraphs.
- **Double Strands**: Every query is strand-aware. Matching the reverse complement will return a different, strand-specific address.

To simulate an HGT event across strains:
```bash
frx hgt-sim
```

## 4. Visualization & REST API

To see the graph and the PanIndex metadata in your browser, PanIndex includes a Cytoscape-based interactive bipartite graph viewer.

### Running with Docker Compose (Recommended)
This will spin up both the API backend and the static UI assets.
```bash
docker compose up -d frx-api
```
The API is secured. To enable DEV mode (no auth), ensure `FRX_API_TOKEN` is unset in your environment. For production, set `FRX_API_TOKEN=your_secure_token`.

### Running manually
1. Start the API server:
   ```bash
   python -m viz.server
   ```
2. Open `viz/index.html` in any modern browser.
3. If auth is enabled, enter your token in the "API Connection" sidebar field.
4. Use **Semantic Zoom** to move between Architectural (HGT/Strains), Functional (Gene clusters), and Atomic (Base pairs) views.

## 5. Running Tests

To verify your installation and implementation (requires pytest):
```bash
python -m pytest tests/ -v
```
The suite covers all biological, mathematical, security (Auth), and parsing layers.
